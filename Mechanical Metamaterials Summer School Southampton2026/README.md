## 📖 About This Repository

This repository contains MATLAB and Python implementations for analysing and designing metamaterial structures for vibration control. The code covers fundamental concepts in vibration analysis, dispersion calculations, and the application of local resonators to suppress unwanted vibrations in cables (beam under axial load).

---

## 🎯 Course Overview

**Vibration Control Using Metamaterials** explores the emerging field of engineered materials designed to control mechanical vibrations. Metamaterials are artificially structured materials that exhibit unique properties not found in nature, such as the ability to stop or manipulate wave propagation.

### What You Will Learn
- Fundamentals of structural vibration
- Metamaterial principles and design
- Local resonator theory and implementation
- Dispersion analysis and wave propagation
- Programming tools for vibration analysis
- Real-world applications in engineering

### Key Concepts Covered
- **Natural Frequencies & Mode Shapes**
- **Receptance (Frequency Response)**
- **Dispersion Diagrams**
- **Wavenumber Analysis**
- **Group Velocity**
- **Stop Bands & Band Gaps**
